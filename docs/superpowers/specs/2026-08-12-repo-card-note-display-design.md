# Repo 卡片备注展示 — 设计文档

- 日期：2026-08-12
- 状态：已按审核反馈修订，待复核

## 背景

Repo 卡片已经支持通过标题栏右侧的备注按钮编辑备注，但保存后的备注只体现在按钮状态和备注筛选中，卡片正文不会直接展示内容。本次在卡片底部补充只读备注展示，让用户无需打开编辑器即可浏览当前备注。

## 需求范围

1. 仅当 `repo.note` 有内容时，在标签选择器下方展示当前备注。
2. 备注默认最多显示两行，超出部分以省略号截断。
3. 仅在内容发生截断时，鼠标悬停展示完整备注。
4. 备注区域在视觉上与 repo 描述、统计信息和标签区分。
5. 保留现有备注编辑、保存、筛选和数据接口行为。

## 实现设计

在 `app/components/RepoCard.tsx` 的 `TagSelect` 后新增备注展示。复用项目已有的 Ant Design `Typography.Paragraph`：

- `ellipsis.rows` 设为 `2`，实现两行截断。
- `ellipsis.tooltip` 传入完整备注，由组件在文本溢出时提供 Tooltip。
- 使用现有的 `FileTextOutlined` 图标标识备注。
- 备注整体放入独立的弱强调容器，使用 Ant Design 主题 token `colorFillTertiary` 作为背景色、`borderRadiusSM` 作为圆角，并用 `paddingXXS`、`paddingXS` 设置内边距。该组合在明暗主题下都会随当前主题变化，不写死颜色。
- 文本使用次要文本色，并将段落底部外边距设为 `0`，使备注与其他信息明显区分且不过度抢占视觉焦点。

备注保存成功后，现有 `RepoList` 会重新获取 repo 列表，因此新增区域会自然显示最新内容，不增加本地同步状态。

## 影响范围

仅修改 `app/components/RepoCard.tsx`。不修改接口、数据库、数据类型、全局样式，也不增加依赖。

## 验收与验证

- 无备注的卡片不渲染备注区域。
- 备注显示在独立的浅色背景容器内，并在明暗主题下保持可读。
- 一至两行备注完整展示，不出现省略号。
- 超过两行的备注显示省略号，悬停可查看完整内容。
- 保存、修改或清空备注后，卡片展示与最新数据一致。
- 运行针对修改文件的 lint，并执行现有测试套件确认无回归。

## 不在本次范围内

- 不调整备注编辑器的交互或位置。
- 不改变备注的存储、清理或筛选语义。
- 不支持展开、折叠、点击复制等额外交互。
